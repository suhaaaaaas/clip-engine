# Phase 0 — the golden set

Ends with one episode labeled by both of us, separately. How often we agree
sets the target the scorer has to beat.

- [ ] **Both:** pick one target channel, a video podcast we both watch, with
      2-4 people on camera
- [ ] **Suhaas:** download 3 recent episodes (local study only; nothing gets
      posted), transcribe them, commit the transcripts
- [ ] **Partner:** set up the repo and confirm the label format in
      `golden/README.md` works when you actually sit down to label
- [ ] **Both, separately:** mark 10 clips per episode with a reason and a type
- [ ] **Both, together:** compare, count overlaps, discuss disagreements, merge
      into `golden/<episode>_merged.csv`
- [ ] **Both:** keep episode 3 held out; never tune against it
- [ ] **Either:** write the first post — what makes a clip good, and where we
      disagreed

## Why labels come first

Every later decision ("is this feature helping?", "is the scorer good enough
to show a creator?") is answered by comparing against these labels. Building
the scorer first means guessing, then arguing about taste.
